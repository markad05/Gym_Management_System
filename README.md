# Gym Management System

A console-based Gym Management System developed in C++ as a **group project**.

## Description
This project simulates the core operations of a gym. It allows basic management of gym members, trainers, and related information through a console-based interface.

## Features
- Manage gym member information
- Store trainer details and specialization
- File-based data handling
- Object-Oriented Programming structure
- Simple console interface

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling

## Note
This project was developed as a **group assignment**, where team members collaborated on the system design, implementation, and debugging.
